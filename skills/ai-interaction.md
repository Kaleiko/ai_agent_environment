# AI Interaction Guidelines

## Communication

- Always request clarification before implementing major refactors or architectural changes
- Provide context when asking for code modifications
- Explain the reasoning behind suggested changes

## Code Review Process

- Review generated code for adherence to project standards before implementation
- Verify that all requirements (docstrings, type hints, tests) are included
